Diário da horta do campus
A equipe da horta precisa registrar as regas para saber quando cada canteiro foi cuidado. A aplicação mantém um diário que pode ser consultado por canteiro.

Dados
Cada canteiro tem nome e cultura plantada. Cada registro de rega guarda o canteiro, a data, o nome fictício de quem fez a rega e uma observação opcional.
Tela

Cadastre e edite registros de rega. Liste os registros do mais recente para o mais antigo, com filtro por canteiro. Mostre a data da última rega de cada canteiro.
Regra

A data da rega deve ser igual ou anterior à data de hoje. Para este diário, há um registro por canteiro por dia.
Teste

Registre regas em dois dias para o mesmo canteiro. Confira a data mais recente e tente registrar outra rega no mesmo dia. Cadastre uma rega de outro canteiro nesse dia.
